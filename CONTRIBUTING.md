# Contribuindo

## Fluxo
1. Crie uma branch a partir de `main`: `git checkout -b feat/minha-feature`
2. Faça commits pequenos e descritivos (padrão Conventional Commits: `feat:`, `fix:`, `docs:`...)
3. Abra um Pull Request descrevendo o que muda e por quê.

## Convenções
- Backend: Python, FastAPI, formatação com `ruff`/`black`.
- Mobile: React Native (Expo), TypeScript quando possível.
- Nada de segredos no repositório — use `.env` (veja `.env.example`).

## Branches
- `main`: estável
- `feat/*`, `fix/*`, `docs/*`: trabalho em progresso

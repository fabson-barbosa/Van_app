# VaiVem — Mobile

Apps em React Native (Expo). Scaffold inicial.

## Rodar localmente

```bash
npm install
npx expo start
```

## Estrutura prevista

```
src/
├── shared/            # design system, api client, hooks
├── motorista/         # fluxo do motorista
├── responsavel/       # fluxo do responsavel
└── gestor/            # fluxo do gestor
```

> Os protótipos visuais de referência estão em `../docs/prototipos/`.
